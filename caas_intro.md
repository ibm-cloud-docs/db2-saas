# What is CaaS?
{: #caas_console}

IBM is introducing a new console experience, built on the Genius Hub framework. This console will gradually replace the current legacy console used with Db2 SaaS.

For end users, the main difference is in the navigation and UI flows. The features remain the same, but the steps to perform tasks may look different in the new console.

Depending on your plan and region, you may see either the legacy console or the new Genius Hub–enabled console.  
{: note}

 This section covers all functionalities where the steps apply to the new Genius Hub–enabled console (CaaS). Follow these instructions if you see the updated UI. If you are still using the legacy console, refer to the corresponding legacy console [section](https://cloud.ibm.com/docs/db2-saas?topic=db2-saas-getting-started) for the correct steps.
{: important}
